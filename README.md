
# ESTORA

**ESTORA** — The Real Estate Social Network

Connect Buyers, Brokers, Property Owners, Developers & Investors on one powerful platform.

---

## Vision
ESTORA = Facebook + Instagram + LinkedIn + Real Estate Marketplace

### Core Principles
- Free for Buyers
- Subscription based for Brokers & Companies
- No commission on property deals (initial model)
- Strict No-Sale of Private Data policy
- Built for India first → then International

---

## User Roles
- **Buyer** → Search, Inquiry, Chat (Completely Free)
- **Broker** → Profile, Listings, Chat, Premium Subscription
- **Property Owner**
- **Investor**
- **Real Estate Company / Developer**

---

## Planned Features (MVP)
1. User Authentication + Role Selection
2. Broker Professional Profile
3. Property Listing (Photos, Videos, Price, Location)
4. Advanced Search (Country, City, Budget, Property Type, BHK)
5. Secure Chat between Buyer & Broker
6. Subscription Plans (Broker Premium + Company Plans)

---

## Tech Stack (Proposed)
- **Mobile App**: Flutter
- **Backend**: Supabase (or Node.js + Express)
- **Database**: PostgreSQL
- **Authentication**: Supabase Auth
- **Storage**: Supabase Storage / Cloudinary
- **Chat**: Supabase Realtime or Stream
